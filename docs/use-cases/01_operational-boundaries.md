# Operational boundaries

Practitioners can import grouped COCO annotations, train or fine-tune models,
run all classical and learned methods, export masks and size descriptors, and
reproduce benchmark evidence. The website replays selected canonical cases and
runs validated light methods on local uploads without sending the image to a
server.

FrothSeg is not a plant-control system, metallurgical recovery estimator, or
claim of plant accuracy. Outputs without physical calibration remain in pixels.
Heavy models are offline jobs; the web provides their evidence and an exportable
command rather than pretending to execute them. Real deployment decisions
require site-specific validation, licensing review, calibration, monitoring,
and operator governance.
