# Temporal analysis

The temporal lane separates automatic discovery from identity propagation.
Synthetic sequences retain exact instance IDs, motion, and event logs. Video
models state their initialization protocol explicitly.

Every registered method is run over every canonical sequence: 15 methods, 5
sequences, 8 frames, 75 published pairs. The release gate fails on any missing
cell.

- [Tracking and event evaluation](01_tracking-and-events.md): the metrics and
  what each one measures.

  matrix, the two prediction modes and why they are never ranked together, the
